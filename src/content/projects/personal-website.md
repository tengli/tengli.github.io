这个网站用于集中展示我的个人介绍、文章、节目和开发项目。

## 项目目标

项目需要同时满足三个目标：

1. 建立长期可维护的个人网站；
2. 作为前端、Git 和部署知识的实战项目；
3. 为未来接入 AI 搜索和问答能力打基础。

## 当前功能

- 首页与个人介绍；
- Markdown 文章系统；
- 节目和项目内容系统；
- GitHub Actions 自动部署；
- 响应式布局。

## 后续计划

未来将逐步加入：

- RSS；
- 内容搜索；
- 自定义域名；
- AI 文章问答；
- 节目文字稿检索。
