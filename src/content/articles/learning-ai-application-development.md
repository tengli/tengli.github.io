过去很长时间里，我的工作重点是产品设计、需求分析和项目协作。

现在，我希望进一步理解软件是怎样被真正构建出来的，并逐步获得独立完成产品原型、数据处理、API 和 AI 应用的能力。

## 为什么从 Python 开始

Python 在数据处理、后端服务和 AI 应用中都有广泛用途。

对我而言，Python 不只是需要学习的一门语言，也是一条连接数据、API 和大语言模型应用的主线。

## 当前学习重点

现阶段主要学习：

- Python 基础与项目结构；
- Git 和 GitHub；
- 自动化测试；
- FastAPI；
- Astro 与基础前端；
- 大语言模型应用。
